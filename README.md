# Features

1. Customized Layout Creation.
   - Allows for the design and customization of office layouts according to the specific needs of the company.
   - Includes intuitive design tools to map out cubicles and work zones.     
2. User Registration and Cubicle Assignment
   - Facilitates the registration of users with their personal and contact information.
   - Enables the assignment of users to specific cubicles based on availability and user requirements.
3. Real-Time Cubicle Status Monitoring
   - Provides real-time updates on the occupancy status of each cubicle.
   - Allows administrators to quickly identify and address any issues related to workspace availability.
4. Work Zone Mapping
   - Maps cubicles within different work zones to help manage office space efficiently.
   - Offers a visual representation of the office layout for easy navigation and planning.
5. Report Generation
- Generates detailed reports in Excel format.
- Reports can include data on cubicle occupancy, user assignments, and overall workspace utilization.
